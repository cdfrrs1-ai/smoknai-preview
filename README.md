# SmoknAi Phone-Ready Preview

Responsive static website prototype; no build tools required.

## Publish for free from your phone with GitHub Pages
1. Sign in at https://github.com and create a **public** repository named `smoknai-preview`.
2. Tap **Add file → Upload files**.
3. Upload `index.html`, `styles.css`, `app.js`, and `manifest.json` from this folder. You can upload this README too.
4. Commit the files.
5. Open repository **Settings → Pages**.
6. Select **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
7. Wait for publishing. GitHub Pages will show your shareable website URL in Settings → Pages.

Public repository files can be seen by anyone. Never upload passwords, private API keys, personal data, or secrets.

## Prototype limits
Chat uses local demo responses. Creative Studio drafts text briefs, not finished audio/video/images. No login, saved account, billing, admin backend, or live AI provider is connected. Real AI must be accessed through a secure backend; never put provider API keys in browser JavaScript. Free services have quotas and terms that can change.
